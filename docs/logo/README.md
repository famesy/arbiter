# arbiter logo

The agent whose turn it is steps up to the board. The others wait in a ring around it, smaller the further back they are in the queue.

| File | Use |
| --- | --- |
| `arbiter-logo.svg` | Fills with `currentColor`, so it takes the text colour when inlined (dashboard, docs). |
| `arbiter-logo-light.svg` | Near-black, for light backgrounds. |
| `arbiter-logo-dark.svg` | Near-white, for dark backgrounds. |

The mark is a single colour. Yellow and red are kept for warnings and errors in the dashboard and are never used in the logo.
